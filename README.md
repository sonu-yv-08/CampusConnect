# CampusConnect

Full-stack web platform connecting university students by shared skills, interests, and academic goals.

## Overview
CampusConnect is designed to empower university students by facilitating meaningful connections across campus. Whether looking for project collaborators, study partners, or skill-sharing peers, CampusConnect bridges the gap between students with matching interests.

## Key Features
- **Skill & Interest-Based Student Matching**: Connect with peers based on complementary technical skills, academic subjects, and shared hobbies.
- **Profile Discovery**: Search and explore rich student profiles to build your academic and project network.
- **Campus Networking**: Foster a collaborative community within the university ecosystem.

## Tech Stack
- **Backend**: Node.js, Express.js
- **Frontend**: JavaScript (ES6+), HTML5, CSS3

## Local Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sonu-yv-08/CampusConnect.git
   cd CampusConnect
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the server**:
   ```bash
   node server.js
   ```
